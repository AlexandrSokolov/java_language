# Deutsch lernen — метод и правила работы

Этот файл — инструкция для Claude. Прочитай его перед любой работой по немецкому, чтобы мне не объяснять всё заново.

## 1. Цели (по приоритету)

1. **B1**: сертификат для гражданства (вероятно, Goethe B1). Готовимся не под конкретный экзамен, а к живому немецкому; сертификат будет следствием.
2. **Немецкий для детей**: читать детские книги дома и помогать дочке. Детские книги — основной источник текстов и слов.
3. **IT и бизнес-немецкий до C1**: обсуждать проекты, проходить собеседования, не выделяться в худшую сторону. Добавляем понемногу уже сейчас (чанки для собеседования, термины IT и бизнеса).

Материалы будет учить и жена (кроме IT). Файлы должны быть самодостаточными: открыла и проговариваешь, ничего планировать не нужно.

## 2. Главный принцип: беглость

- **Главная цель — беглая и правильная речь без раздумий.** Мозг должен строить связи на автомате, а не вспоминать правила. Пусть словарь будет меньше, лишь бы речь текла.
- **Говорим связями (чанками), а не словами.** Учим целые блоки: *Wenn du willst, kannst du es nehmen.* Знакомый блок в разговоре узнаётся целиком, и внимание идёт только на новое.
- **Грамматика и связи — одно направление.** Правило один раз понимаем, а потом вбиваем его через десятки чанков, проговорённых вслух. Никто не вспоминает «auf + Dativ», в голове просто сидит *auf dem Sofa*.
- **Не зубрим правила.** Грамматика встроена в вопросы и ситуации: вопрос сам ведёт к нужной форме (*Wohin?* → Akkusativ, *Wo?* → Dativ).
- **Каждое слово проходит через много грамматических «стаков»**: падежи, Perfekt, Präteritum, модальные глаголы, Konjunktiv, Imperativ, придаточные.
- Тренируем **вслух**. Лучше всего живой разговор голосом.

## 3. Правила для слов

- **Существительное никогда без артикля** и по возможности сразу в чанке: *mit dem Fahrrad fahren*, *aufs Fahrrad steigen*.
- **dieser / diese / dieses / diesem** помогают слышать род и падеж: окончания повторяют артикль, но звучат чётче.
- **Абстрактные слова** учим через мини-ситуацию, а не через картинку. Абстрактные глаголы всегда учим с «прицепом»: *denken an* + Akk, *warten auf*, *sich freuen auf / über*. Короткая русская подсказка при первом знакомстве допустима.
- **Картинки**: по умолчанию эмодзи. Слова, к которым нет эмодзи, Claude выносит в список «картинки найти позже», их ищу я сам.
- **Ударение**: отмечаем только при первом вводе слова и только если оно не на первом слоге, ударный слог большими буквами: *KaNINchen, CouSIN*. Где работает правило, не отмечаем: приставки *be-, ge-, er-, ver-, ent-, zer-* безударные, отделяемые приставки ударные.
- **Минимум русского**: названия файлов, ступеней и всё содержимое — на немецком.

## 4. Типы документов

1. **Тематические файлы** (Gefühle, Familie_Geschwister, Tiere, …): слова одной темы, пропущенные через ступени.
2. **Семантические поля** (например, Verben des Sagens: sagen, rufen, flüstern, erklären…): пополняются постепенно, когда слово встречается в новом тексте. Не заполняем сразу.
3. **Связки** (weil, deshalb, trotzdem, obwohl, wenn, dass, damit…) — фундамент беглости.
4. **IT / Business** — отдельно, только для меня.

Новая книга обычно **расширяет существующие темы**, а не создаёт новые. Тогда Claude дополняет существующий файл и возвращает мне обновлённую версию.

## 5. Источники и рабочий процесс

- **Детская книга**: я присылаю вырезки абзацев (не тяжёлые PDF). Короткие книги шлю целиком, Claude раскладывает слова по темам и выделяет чанки. Длинные тексты шлю по одному.
- **Учебник (A2–B1)**: присылаю тему урока и фото словаря, Claude делает файл по этой лексике.
- Сначала **обсуждаем в чате**: какие темы и какие ступени. **Файл Claude создаёт только по моему явному запросу.**
- В чате отвечать коротко: 1–3 абзаца, без стен текста. Длинный комментарий делить на части и обсуждать по одной.

## 6. Хранение и формат файлов

**Главная версия — MD** (в проекте и у меня в GitLab). **`.docx` — экспорт** для работы в Google Docs и для жены. Claude правит MD и по запросу делает из него `.docx`.

Папки в проекте:
- `Methode/` — этот файл
- `Themen/` — тематические файлы
- `Wortfelder/` — семантические поля
- `Verbindungen/` — связки
- `IT_Business/`
- `Quellen/` — разобранные книги и уроки

**Формат MD:** `# Тема`, затем для каждой ступени свой заголовок `## Stufe 1 — …` и своя таблица:

```
| Situation / Frage | Antwort |
|---|---:|
| Julian ist wütend: „Blödes Fahrrad!“ | Er schimpft. |
| – Amelie braucht keine Windeln mehr.<br>– Und gestern? | – Sie ist stolz.<br>– Gestern war sie auch stolz. |
```
- Правая колонка выровнена по правому краю.
- Связанные строки (мини-диалог, который нельзя разрывать) стоят в одной ячейке, каждая строка с `– `, разделены `<br>`.
- Подчёркивания в пропусках экранируются: `W\_\_`.

**Формат .docx:** альбомная ориентация, одна таблица на две колонки. Заголовок ступени — объединённая строка по центру. Слева ситуация, справа ответ по правому краю. Связанные строки — отдельные абзацы в одной ячейке.

Названия файлов по-немецки: `Gefühle`, `Familie_Geschwister`.

## 7. Ступени (Stufen)

| Stufe | Что тренирует | Пример |
|---|---|---|
| 1 — Situation → Wort | понять слово из контекста | *Julian ist wütend: „Blödes Fahrrad!"* → *Er schimpft.* |
| 2 — Fragen | правильный вопрос + падеж | *W\_\_ tröstet Mama? (Paul)* → *(Wen?) Sie tröstet ihn.* |
| 3 — Imperativ | du / ihr / Sie | *Die Kinder rufen im Bus böse Wörter.* → *Schimpft nicht so laut!* |
| 4 — Zeiten | Präsens, Perfekt, Präteritum (книжное), werden, würde/wäre, Modalverben | *Und gestern?* → *Gestern hat er geschimpft.* |
| 5 — Ausdrücke | готовые фразы на каждый день, собеседование, экзамен | *Ein Kollege fragt: „Wie geht's?"* → *Ich kann mich nicht beklagen.* |
| 6 — Adjektiv + Nomen | окончания прилагательных, mein/dieser | *Er spielt mit sein_ klein_ Schwester.* → *mit seiner kleinen Schwester* |
| 6 (альтернатива) — Spiegel | по ответу придумать вопрос, коротко, 1 на слово | *Er erklärt es seiner Schwester.* → *Wem erklärt Leo das?* |
| 7 — Nebensätze | weil, dass, wenn, damit, ob, obwohl, deshalb, trotzdem | *Warum ist Julian wütend? (umfallen)* → *Er schimpft, weil er umgefallen ist.* |

### Правила составления
- **Левая часть не должна подсказывать ответ.** В ней нет нужного глагола или формы. Только ситуация, из которой ответ однозначен, даже если исходный текст забыт.
- **Ответ — целая фраза**, а не одно слово.
- **Пропуски**:
  - `_` — только окончание: *sein_ Hund* → *seinem*
  - `__` — часть слова: *W__ setzt du dich?* → *Wohin*
  - `___` — целое слово (артикль, предлог, местоимение — всё, что отделено пробелами)
- В Stufe 2 справа в скобках правильный вопрос: *(Wem?)*, *(Mit wem?)*, *(Worüber?)*. Про людей спрашиваем *über wen / mit wem*, про вещи — *worüber / womit*.
- В Imperativ используем и **du**, и **ihr** (обращение к нескольким детям), иногда **Sie**.
- В Stufe 7 слева живой вопрос + голые подсказки в инфинитиве, без союза и без готовой формы. Каждый союз примерно по одному разу, без лишних повторов.
- **Объём**: не раздувать. Структуры повторяются от файла к файлу, поэтому 1–2 примера на слово в ступени достаточно.

### Грамматические заметки
- В разговоре прошлое передаётся через **Perfekt** (*hat gesagt*). Präteritum — для книг, а в речи только *war, hatte* и модальные (*konnte, wollte*).
- Будущее в речи обычно передаётся через Präsens + *morgen*. *werden* — для обещаний и прогнозов.

## 8. Тренировки с Claude

- Я присылаю файл, его часть или говорю тему (можно несколько тем вместе). Claude даёт **левую колонку вразброс**, по одной-две строки, я отвечаю по-немецки (часто голосом), Claude исправляет ошибки.
- Связанные строки (одна ячейка) никогда не разрывать и порядок внутри не менять.
- Claude подмешивает **новые ситуации** с теми же словами, чтобы ответ не запоминался по месту в списке. В этом главное разнообразие.
- Короткие живые диалоги по теме: я отвечаю короткими фразами, Claude поправляет.
- Повторение по расписанию веду сам в Google Docs. Сторонние инструменты (Anki и подобные) не предлагать.
