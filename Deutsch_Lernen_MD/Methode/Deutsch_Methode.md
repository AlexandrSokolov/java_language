# Deutsch lernen — метод и правила работы

Этот файл — инструкция для Claude. Прочитай его перед любой работой по немецкому, чтобы мне не объяснять всё заново.

## 1. Цели (по приоритету)

1. **B1**: сертификат для гражданства (вероятно, Goethe B1). Готовимся не под конкретный экзамен, а к живому немецкому; сертификат будет следствием.
2. **Немецкий для детей**: читать детские книги дома и помогать дочке. Детские книги — основной источник текстов и слов.
3. **IT и бизнес-немецкий до C1**: обсуждать проекты, проходить собеседования, не выделяться в худшую сторону. Добавляем понемногу уже сейчас (чанки для собеседования, термины IT и бизнеса).

Материалы будет учить и жена (кроме IT). Файлы должны быть самодостаточными: открыла и проговариваешь, ничего планировать не нужно.

## 2. Главный принцип: беглость

- **Главная цель — беглая и правильная речь без раздумий.** Мозг должен строить связи на автомате, а не вспоминать правила. Пусть словарь будет меньше, лишь бы речь текла.
- **Говорим связями (чанками), а не словами.** Учим целые блоки: *Wenn du willst, kannst du es nehmen.* Знакомый блок в разговоре узнаётся целиком, и внимание идёт только на новое.
- **Грамматика и связи — одно направление.** Правило один раз понимаем, а потом вбиваем его через десятки чанков, проговорённых вслух. Никто не вспоминает «auf + Dativ», в голове просто сидит *auf dem Sofa*.
- **Не зубрим правила.** Грамматика встроена в вопросы и ситуации: вопрос сам ведёт к нужной форме (*Wohin?* → Akkusativ, *Wo?* → Dativ).
- **Каждое слово проходит через много грамматических «стаков»**: падежи, Perfekt, Präteritum, модальные глаголы, Konjunktiv, Imperativ.
- Тренируем **вслух**. Лучше всего живой разговор голосом.

## 3. Правила для слов

- **Существительное никогда без артикля** и по возможности сразу в чанке: *mit dem Fahrrad fahren*, *aufs Fahrrad steigen*.
- **dieser / diese / dieses / diesem** помогают слышать род и падеж: окончания повторяют артикль, но звучат чётче.
- **Абстрактные слова** учим через мини-ситуацию, а не через картинку. Абстрактные глаголы всегда учим с «прицепом»: *denken an* + Akk, *warten auf*, *sich freuen auf / über*. Короткая русская подсказка при первом знакомстве допустима.
- **Картинки**: по умолчанию эмодзи. Слова, к которым нет эмодзи, Claude выносит в список «картинки найти позже», их ищу я сам.
- **Ударение**: отмечаем только при первом вводе слова и только если оно не на первом слоге, ударный слог большими буквами: *KaNINchen, CouSIN*. Где работает правило, не отмечаем: приставки *be-, ge-, er-, ver-, ent-, zer-* безударные, отделяемые приставки ударные.
- **Минимум русского**: названия файлов, ступеней и всё содержимое — на немецком.

## 4. Типы документов

1. **Тематические файлы** (Gefühle, Familie_Geschwister, Tiere, …): слова одной темы, пропущенные через ступени.
2. **Семантические поля** (например, Verben des Sagens, Gelingen_Scheitern): одна группа глаголов — один файл. Пополняются постепенно, когда слово встречается в новом тексте. Файл может начинаться с короткой рамки `>` (2–4 строки, как в грамматических файлах) с главной осью группы: кто подлежащее, haben/sein в Perfekt, разговорное/формальное.
3. **Связки** (weil, deshalb, trotzdem, obwohl, wenn, dass, damit…) — фундамент беглости. **Nebensätze тренируются только здесь**, изолированно, а не в лексических файлах.
4. **Грамматика** (`Grammatik/`): порядок слов, модальные глаголы, lassen, Passiv и т. п.
5. **IT / Business** — отдельно, только для меня.

Новая книга обычно **расширяет существующие темы**, а не создаёт новые. Тогда Claude дополняет существующий файл и возвращает мне обновлённую версию.

## 5. Источники и рабочий процесс

- **Детская книга**: я присылаю вырезки абзацев (не тяжёлые PDF). Короткие книги шлю целиком, Claude раскладывает слова по темам и выделяет чанки. Длинные тексты шлю по одному.
- **Учебник (A2–B1)**: присылаю тему урока и фото словаря, Claude делает файл по этой лексике.
- Сначала **обсуждаем в чате**: какие темы и какие ступени. Перед новым файлом Claude показывает структуру на примере одного слова. **Файл Claude создаёт только по моему явному запросу.**
- В чате отвечать коротко: 1–3 абзаца, без стен текста. Длинный комментарий делить на части и обсуждать по одной.

## 6. Хранение и формат файлов

**Главная версия — MD** (в проекте и у меня в GitLab). **`.docx` — экспорт** для жены, если понадобится. Claude правит MD и по запросу делает из него `.docx`.

**Google Docs** — в будущем только для карточек «картинка → слово» (маленькие картинки для быстрых ассоциаций, можно без контекста).

Папки в проекте:
- `Methode/` — этот файл
- `Themen/` — тематические файлы
- `Wortfelder/` — семантические поля
- `Verbindungen/` — связки и Nebensätze
- `Grammatik/` — грамматика (`Satzgrammatik/`, `Wortgrammatik/`)
- `IT_Business/`
- `Quellen/` — разобранные книги и уроки

**Формат MD:** `# Тема`, затем для каждой ступени свой заголовок `## Stufe 1a — …` и своя таблица:

```
| Situation / Frage | Antwort |
|---|---:|
| Julian ist wütend: „Blödes Fahrrad!“ | Er schimpft. |
| – Amelie braucht keine Windeln mehr.<br>– Und gestern? | – Sie ist stolz.<br>– Gestern war sie auch stolz. |
```
- Правая колонка выровнена по правому краю.
- Связанные строки (мини-диалог, который нельзя разрывать) стоят в одной ячейке, каждая строка с `– `, разделены `<br>`.
- Подчёркивания в пропусках экранируются: `W\_\_`.

**Формат .docx:** альбомная ориентация, одна таблица на две колонки. Заголовок ступени — объединённая строка по центру. Слева ситуация, справа ответ по правому краю. Связанные строки — отдельные абзацы в одной ячейке.

Названия файлов по-немецки: `Gefühle`, `Familie_Geschwister`.

## 7. Ступени (Stufen)

| Stufe | Что тренирует | Пример |
|---|---|---|
| 1a — Nomen | существительное из контекста (всегда первая) | *Gummi im Mund, das Baby ist still.* → *Das ist sein Schnuller.* |
| 1b — Verben | глагол из контекста | *Schnuller im Mund.* → *Er nuckelt.* |
| 1c — Adjektive / Adverbien | прилагательные, наречия (по мере надобности) | *Tränen in den Augen.* → *Er ist traurig.* |
| 2 — Artikel (der / den / dem) | склонённый указательный артикль в конце фразы, без существительного | *Das Baby weint. (Schnuller, geben)* → *Gib mir den!* |
| 3 — Fragen | правильный вопрос + падеж | *W\_\_ tröstet Mama? (Paul)* → *(Wen?) Sie tröstet ihn.* |
| 4 — Imperativ | du / ihr / Sie, только глаголы файла | *Die Kinder rennen mit dem Kinderwagen.* → *Schiebt den Kinderwagen langsam!* |
| 5 — Zeiten | Präsens, Perfekt, Präteritum (книжное), werden, würde/wäre, Modalverben | *Und gestern?* → *Gestern hat er geschimpft.* |
| 6 — Ausdrücke | готовые фразы на каждый день, собеседование, экзамен | *Das Baby riecht nicht gut.* → *Die Windel ist voll.* |
| 7a — Adjektiv + Nomen | окончания прилагательных, mein/dieser | *Er spielt mit sein_ klein_ Schwester.* → *mit seiner kleinen Schwester* |
| 7b — Adverb + Verb | устойчивое наречие при глаголе | *Bis Freitag? Viel Zeit, kleine Aufgabe.* → *Das schaffen wir locker.* |
| 7 (альтернатива) — Spiegel | по ответу придумать вопрос, коротко, 1 на слово | *Er erklärt es seiner Schwester.* → *Wem erklärt Leo das?* |

**Nebensätze в лексические файлы не входят.** Это отдельный навык: беглость союзов и порядка слов, а не применение слова, и длинная левая часть ломает быстрый темп. Тренируем изолированно в `Verbindungen/`. Управление самого слова (*es schaffen, … zu tun*; *Mir gelingt es, … zu*) — не Nebensatz, оно остаётся в Zeiten и Ausdrücke.

### Нумерация и пропуски
- Номера ступеней **одинаковые во всех файлах**, даже если какие-то пропущены: запрос «Stufe 3 из всех файлов» должен работать везде.
- Если в файле нет новых существительных (семантическое поле глаголов), Stufe 2 и 7a пропускаем.

### Главное правило: каждая ступень — только слова этого файла
- Ступени 2–7 тренируют **только новые слова файла**. В каждой строке ответ строится вокруг слова файла: артикль, падеж, время, императив, выражение — именно для него.
- Общие глаголы и слова (*setzen, bringen, geben, sein, nehmen, verlieren, brauchen…*) **не становятся предметом тренировки**. Они допустимы только как фон в ситуации, если без них никак.
- Если для слова в ступени нет естественной ситуации, строку не делаем. Ступень из 1–2 строк или без ступени вовсе — это нормально. Лучше пусто, чем общая речь.

### Stufe 1: по частям речи, без взаимных подсказок
- В файлах с лексикой Stufe 1 **делится по частям речи**, каждая часть — своя таблица: **1a — Nomen** (всегда первая), **1b — Verben**, при необходимости **1c — Adjektive / Adverbien** и дальше.
- В семантических полях с одной частью речи (например, Verben des Sagens) Stufe 1 не делится.
- **Слева нет ни одного нового слова этого файла.** В 1a нет новых глаголов и других новых существительных: *Schnuller* не описываем через *nuckeln*, *Kinderwagen* — через *schieben*, *Windel* — через *Töpfchen*. Иначе строки подсказывают друг другу, и я отвечаю по памяти о соседней строке, а не по смыслу.
- **1b может опираться на существительные из 1a** (они уже пройдены): *Schnuller im Mund.* → *Er nuckelt.* Но не на другие новые глаголы. Так же 1c опирается на 1a и 1b.
- **Слева предельно коротко**: 2–6 слов, только зацепки, можно без полного предложения. Прочитал → понял → сразу ответил. Справа — целая фраза.

### Stufe 2: Artikel
- Стоит после 1a/1b и перед Fragen. Цель — закрепить артикль **сразу в склонённой форме**, а не голое der/die/das.
- Слева короткая ситуация, в скобках существительное **без артикля** + глагол-подсказка. Справа короткая фраза, **указательный артикль в конце**, существительного нет: *Gib mir den! Sie liegt auf der. Wo ist das?*
- Вперемешку **Nominativ** (*Wo ist der?*), **Akkusativ** (*Zeig mir die!*), **Dativ** (*aus dem, auf der*) и множественное число (*die / die / denen*). Строки одного существительного не ставим подряд.
- По возможности используем глаголы файла: *Er nuckelt an dem. Er schiebt den.*
- Genitiv не берём: в речи он заменяется на *von dem*.

### Правила составления
- **Левая часть не должна подсказывать ответ.** В ней нет нужного глагола или формы. Только ситуация, из которой ответ однозначен, даже если исходный текст забыт.
- **Ответ — целая фраза**, а не одно слово (кроме Stufe 2 и коротких ответов на вопрос в Stufe 3).
- **Пропуски**:
  - `_` — только окончание: *sein_ Hund* → *seinem*
  - `__` — часть слова: *W__ setzt du dich?* → *Wohin*
  - `___` — целое слово (артикль, предлог, местоимение — всё, что отделено пробелами)
- **Stufe 3 (Fragen)**:
  - Подсказка в скобках **без артикля**: *(Krabbeldecke)*, а не *(die Krabbeldecke)*. Артикль и падежную форму вспоминаю сам.
  - **Предлог слева никогда не показываем**, на его месте `___`: *\_\_\_ w\_\_ schafft ihr das? (Montag)* → *(Bis wann?) Bis Montag.* Не *Bis w\_\_ …*: предлог — половина ответа.
  - Справа в скобках правильный вопрос: *(Wem?)*, *(Mit wem?)*, *(Worüber?)*. Про людей спрашиваем *über wen / mit wem*, про вещи — *worüber / womit*.
- **Stufe 4 (Imperativ)**: только глаголы файла в повелительной форме: *Schieb den Kinderwagen langsam!* Не *Setz dich!, Sei leise!, Bring mir…* Используем и **du**, и **ihr** (обращение к нескольким детям), иногда **Sie**. Если у глагола нет естественного императива (*gelingen, schiefgehen, schaffen*), строки нет. Подбадривания по смыслу группы (*Augen zu und durch!, Beiß die Zähne zusammen!*) идут в Stufe 6, и только вместе с глаголом файла: *Augen zu und durch, wir schaffen das!*
- **Stufe 5 (Zeiten)**: время тренируем на глаголах файла: *hat gewickelt, ist eingeschlafen, nuckelte*. Не *hat verloren, brauchte*.
- **Stufe 6 (Ausdrücke)**: каждое выражение содержит слово файла.
- **Stufe 7a**: существительное в связке — из файла.
- **Stufe 7b**: глагол из файла + **устойчивое наречие именно этого глагола**, самое распространённое: *locker / spielend / kaum schaffen, einwandfrei funktionieren, reibungslos klappen, kläglich scheitern*. Не обстоятельства времени и места (*gerade noch, in letzter Sekunde, sofort*): они относятся к ситуации, а не к глаголу. Нет такой пары — строку не делаем.
- **Объём**: не раздувать. Структуры повторяются от файла к файлу, поэтому 1–2 примера на слово в ступени достаточно.

### Грамматические заметки
- В разговоре прошлое передаётся через **Perfekt** (*hat gesagt*). Präteritum — для книг, а в речи только *war, hatte* и модальные (*konnte, wollte*).
- Будущее в речи обычно передаётся через Präsens + *morgen*. *werden* — для обещаний и прогнозов.

## 8. Тренировки с Claude

- Я присылаю файл, его часть или говорю тему (можно несколько тем вместе). Claude даёт **левую колонку вразброс**, по одной-две строки, я отвечаю по-немецки (часто голосом), Claude исправляет ошибки.
- Связанные строки (одна ячейка) никогда не разрывать и порядок внутри не менять.
- Claude подмешивает **новые ситуации** с теми же словами, чтобы ответ не запоминался по месту в списке. В этом главное разнообразие.
- Короткие живые диалоги по теме: я отвечаю короткими фразами, Claude поправляет.
- Повторение по расписанию веду сам в Google Docs. Сторонние инструменты (Anki и подобные) не предлагать.
