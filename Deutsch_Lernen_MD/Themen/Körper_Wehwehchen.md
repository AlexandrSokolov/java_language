# Körper & Wehwehchen

## Stufe 1 — Situation → Was?

| Situation / Frage | Antwort |
|---|---:|
| Klara macht mit den Zähnen „Happ!“ in Teddys Ohr. | Sie beißt Teddy. |
| Papa macht mit dem Mund Luft auf das Ohr. | Er pustet. |
| Lukas hat in der Nacht Schmerzen hier (zeigt auf den Bauch). | Er hat Bauchschmerzen. |
| Ein kleines Ding, du klebst es auf die Wunde. | Das ist ein Pflaster. |
| Teddy hat ein Loch im Ohr. | Sein Ohr ist verletzt. |
| Damit hörst du. | Mit den Ohren. |
| Damit riechst du. | Mit der Nase. |
| Da wächst das Baby bei Mama. | Im Bauch. |
| Wo hat Jonathan den Schnuller? | Im Mund. |
| Jonas ist wütend und macht laut „Bum!“ auf den Boden. | Er stampft mit dem Fuß auf. |
| Mama trägt Amelie ganz nah bei sich. | Sie nimmt sie auf den Arm. |

## Stufe 2 — Fragen

| Situation / Frage | Antwort |
|---|---:|
| W\_\_ hat Klara gebissen? (Teddy) | (Wen?) Sie hat Teddy gebissen. |
| W\_\_\_ hat sie ihn gebissen? (das Ohr) | (Wohin?) Ins Ohr. |
| W\_\_\_ pustet Papa? (das Ohr, verletzt) | (Worüber?) Über das verletzte Ohr. |
| W\_\_\_ klebt Luisa das Pflaster? (das Ohr) | (Wohin?) Aufs Ohr. |
| W\_\_ tut dir weh? (der Bauch) | (Was?) Der Bauch tut mir weh. |
| W\_\_ tut der Bauch weh? (Lukas) | (Wem?) Ihm tut der Bauch weh. |
| W\_\_\_ stampft Jonas auf? (der Fuß) | (Womit?) Mit dem Fuß. |
| W\_\_\_ nimmt Papa Luisa? (der Arm) | (Wohin?) In den Arm. |
| W\_\_\_ stupst Oskar Paul an? (die Nase) | (Womit?) Mit seiner Nase. |
| W\_\_ hatte Lukas Bauchschmerzen? (die Nacht) | (Wann?) In der Nacht. |

## Stufe 3 (Imperativ)

| Situation / Frage | Antwort |
|---|---:|
| Dein Sohn beißt seine Schwester. | Beiß deine Schwester nicht! |
| Deine Tochter ist hingefallen. Du willst die Stelle sehen. | Zeig mal her! |
| Die Suppe ist sehr heiß. Die Kinder wollen sofort essen. | Pustet erst! |
| Es blutet ein bisschen. Dein Sohn soll helfen. | Hol mir bitte ein Pflaster! |
| Dein Kind hat Bauchschmerzen. | Bleib heute im Bett! |
| Das Kind steckt eine Erbse in die Nase. | Steck das nicht in die Nase! |
| Die Kinder kommen vom Spielplatz und wollen essen. | Wascht euch die Hände! |
| Der Arzt will in deinen Hals schauen. Was sagt er? | Machen Sie bitte den Mund auf! |

## Stufe 4 (Zeiten)

| Situation / Frage | Antwort |
|---|---:|
| Teddy hat ein Loch im Ohr. Was hat Klara gemacht? | Sie hat Teddy ins Ohr gebissen. |
| Und was hat Papa dann gemacht? (das Ohr) | Er hat über das Ohr gepustet. |
| Teddy hat jetzt ein Pflaster. Was hat Luisa gemacht? | Sie hat ein Pflaster draufgeklebt. |
| – Lukas in der Nacht? (Bauchschmerzen)<br>– Und jetzt? (müde) | – Er hatte Bauchschmerzen.<br>– Deshalb ist er jetzt so müde. |
| Das Ohr war rot. Und jetzt? (besser) | Jetzt ist es besser geworden. |
| Wie steht es im Buch? (endlich, alles, wieder gut) | Endlich war alles wieder gut. |
| Der Bauch tut immer noch weh. Was machst du morgen? | Morgen gehe ich zum Arzt. |
| Dein Kind hat in der Nacht hohes Fieber. Und du? | Ich würde den Arzt anrufen. |

## Stufe 5 (Ausdrücke)

| Situation / Frage | Antwort |
|---|---:|
| Dein Kind ist hingefallen und weint. | Wo tut's weh? |
| Du pustest auf die Stelle und sagst: | Gleich ist es wieder gut. |
| Beim Arzt: Dein Bauch tut weh. | Ich habe Bauchschmerzen. |
| Du rufst morgens in der Kita an. Dein Sohn bleibt zu Hause. | Mein Sohn ist krank, er kommt heute nicht. |
| Du rufst deinen Chef an. Du kannst heute nicht arbeiten. | Ich bin krank und kann heute nicht kommen. |
| Ein Kollege ist krank. | Gute Besserung! |
| Teddy hat ein verletztes Ohr. | Armer Teddy! |
| Das Pflaster ist drauf, das Kind lacht wieder. | Endlich ist alles wieder gut. |

## Stufe 6 (Adjektiv + Nomen)

| Situation / Frage | Antwort |
|---|---:|
| Das Ohr ist verletzt. Papa pustet über das verletzt\_ Ohr. | Papa pustet über das verletzte Ohr. |
| Die Nase ist weich. Oskar hat ein\_ weich\_ Nase. | Oskar hat eine weiche Nase. |
| Der Bauch ist dick, ein Baby ist drin. Mama hat ein\_ dick\_ Bauch. | Mama hat einen dicken Bauch. |
| Das Pflaster ist bunt. Luisa klebt ein bunt\_ Pflaster drauf. | Luisa klebt ein buntes Pflaster drauf. |
| Die Hände sind schmutzig. Mit schmutzig\_ Händen essen wir nicht. | Mit schmutzigen Händen essen wir nicht. |
| Teddy ist arm. Papa tröstet d\_ arm\_ Teddy. | Papa tröstet den armen Teddy. |
| Die Füße sind kalt. Ich habe kalt\_ Füße. | Ich habe kalte Füße. |
| Die Bauchschmerzen sind blöd. Dies\_ blöd\_ Bauchschmerzen! | Diese blöden Bauchschmerzen! |

## Stufe 7 (Nebensätze)

| Situation / Frage | Antwort |
|---|---:|
| Warum weint Luisa? (Klara, Teddy beißen) | Sie weint, weil Klara Teddy gebissen hat. |
| Wozu pustet Papa? (es, nicht mehr wehtun) | Er pustet, damit es nicht mehr wehtut. |
| Was sagt Mama über Lukas? (in der Nacht, Bauchschmerzen haben) | Mama sagt, dass er in der Nacht Bauchschmerzen hatte. |
| Wann gehst du zum Arzt? (die Schmerzen, nicht aufhören) | Ich gehe zum Arzt, wenn die Schmerzen nicht aufhören. |
| Der Arzt fragt höflich. (wehtun, wo?) | Können Sie mir zeigen, wo es wehtut? |
| Lukas ist müde. Bleibt er zu Hause? (mit in den Zoo gehen) | Obwohl er müde ist, geht er mit in den Zoo. |
