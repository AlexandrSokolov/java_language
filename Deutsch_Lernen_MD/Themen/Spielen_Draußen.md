# Spielen & Draußen

## Stufe 1 — Situation → Was?

| Situation / Frage | Antwort |
|---|---:|
| Jonas und Lara rutschen, klettern und buddeln. Wo sind sie? | Sie sind auf dem Spielplatz. |
| Lena sitzt darauf und fliegt hin und her. | Sie schaukelt auf der Schaukel. |
| Linus und Leon liegen zwischen zwei Apfelbäumen. | Sie liegen in der Hängematte. |
| Mia und Luca haben etwas am Himmel, an einer langen Schnur. | Das ist ihr Drachen. |
| Marie fährt, aber ihr Rad hat keine Pedale. | Sie fährt Laufrad. |
| Julian hat ein richtiges Rad mit Pedalen bekommen. | Das ist ein Fahrrad. |
| Ella hat Rot, Blau, Grün und Gelb in einer Schachtel. | Das sind ihre Buntstifte. |
| Jonas sitzt oben und fährt schnell nach unten. | Er rutscht. |
| Jonas geht mit Händen und Füßen nach oben. | Er klettert. |
| Theo sitzt im Sandkasten mit einer Schaufel. | Er buddelt im Sand. |
| Finn und Ella machen ein Bild vom Kuschelhasen. | Sie malen. |

## Stufe 2 — Fragen

| Situation / Frage | Antwort |
|---|---:|
| W\_\_\_ gehen die Kinder? (der Spielplatz) | (Wohin?) Auf den Spielplatz. |
| W\_\_ spielen die Kinder? (der Spielplatz) | (Wo?) Auf dem Spielplatz. |
| W\_\_ sitzt Lena? (die Schaukel) | (Wo?) Auf der Schaukel. |
| W\_\_\_ klettert Jonas? (der Baum) | (Wohin?) Auf den Baum. |
| W\_\_ hängt der Drachen? (das Dach) | (Wo?) Auf dem Dach. |
| W\_\_\_ holen sie den Drachen herunter? (das Dach) | (Woher?) Vom Dach. |
| W\_\_\_ malt Finn? (die Buntstifte) | (Womit?) Mit den Buntstiften. |
| W\_\_\_ fährt Marie? (das Laufrad) | (Womit?) Mit dem Laufrad. |
| W\_\_ hat Julian sein Laufrad gegeben? (Marie) | (Wem?) Er hat es Marie gegeben. |
| W\_\_ buddelt Theo? (der Sand) | (Wo?) Im Sand. |

## Stufe 3 (Imperativ)

| Situation / Frage | Antwort |
|---|---:|
| Dein Sohn klettert sehr hoch auf den Baum. | Kletter nicht so hoch! |
| Die Kinder sitzen zu zweit auf der Schaukel und fliegen hoch. | Schaukelt nicht so wild! |
| Deine Tochter will rutschen, aber unten sitzt noch ein Kind. | Rutsch noch nicht, unten ist ein Kind! |
| Es fängt an zu regnen, die Kinder sind auf dem Spielplatz. | Kommt schnell nach Hause! |
| Dein Sohn hat neue Buntstifte, seine Schwester will auch malen. | Lass deine Schwester auch malen! |
| Dein Sohn fährt mit dem Fahrrad zur Straße. | Fahr vorsichtig! |
| Die Kinder werfen Sand. | Werft keinen Sand! |
| Es ist kalt, und die Kinder wollen raus. | Zieht eure Jacken an! |

## Stufe 4 (Zeiten)

| Situation / Frage | Antwort |
|---|---:|
| Gestern auf dem Spielplatz: Jonas (rutschen, klettern) | Gestern ist er gerutscht und geklettert. |
| Und Lena gestern? (die Schaukel) | Sie hat geschaukelt. |
| Julian ist umgefallen. Und dann? | Dann ist er wieder aufgestiegen. |
| Mia und Luca: der Drachen und das Dach. Hat es geklappt? | Ja, sie haben ihn vom Dach heruntergeholt. |
| Finn und Ella gestern mit den neuen Stiften? | Sie haben ein Bild gemalt. |
| Wie steht es im Buch? (Marie, stolz, losfahren) | Stolz fuhr sie los. |
| Morgen scheint die Sonne. Was macht ihr? | Morgen gehen wir auf den Spielplatz. |
| Es regnet. Und ohne Regen? | Dann würden wir draußen spielen. |
| Was hast du als Kind gern gemacht? (Bäume) | Als Kind bin ich gern auf Bäume geklettert. |

## Stufe 5 (Ausdrücke)

| Situation / Frage | Antwort |
|---|---:|
| Die Kinder sitzen den ganzen Tag drinnen. | Geht doch mal raus! |
| Draußen scheint die Sonne. Du schlägst vor: | Lass uns rausgehen! |
| Es ist spät, du rufst die Kinder vom Spielplatz. | Wir gehen jetzt nach Hause! |
| Dein Kind will noch nicht gehen. | Noch fünf Minuten! |
| Zwei Kinder wollen auf die Schaukel. Du sagst zum zweiten: | Jetzt bist du dran! |
| Ein Kind will mit anderen Kindern spielen. | Darf ich mitspielen? |
| Viele Kinder, alle laut, alle spielen. | Hier ist ja viel los! |
| Dein Sohn fällt vom Fahrrad und schämt sich. | Das kann jedem mal passieren! |
| Beim zweiten Versuch fährt Julian schon gut. | Diesmal klappt es schon viel besser! |
| Die ersten Tropfen fallen. | Es fängt an zu regnen. |

## Stufe 6 (Adjektiv + Nomen)

| Situation / Frage | Antwort |
|---|---:|
| Die Schaukel ist neu. Lena sitzt auf d\_ neu\_ Schaukel. | Lena sitzt auf der neuen Schaukel. |
| Der Drachen ist rot. Mia sucht ihr\_ rot\_ Drachen. | Mia sucht ihren roten Drachen. |
| Das Fahrrad ist groß. Julian sitzt auf sein\_ groß\_ Rad. | Julian sitzt auf seinem großen Rad. |
| Das Laufrad ist alt. Marie bekommt d\_ alt\_ Laufrad von Julian. | Marie bekommt das alte Laufrad von Julian. |
| Die Stifte sind neu. Ella hat neu\_ Buntstifte. | Ella hat neue Buntstifte. |
| Die Stifte sind neu. Mit ihr\_ neu\_ Stiften malen sie ein Bild. | Mit ihren neuen Stiften malen sie ein Bild. |
| Der Spielplatz ist schön. Wir gehen auf ein\_ schön\_ Spielplatz. | Wir gehen auf einen schönen Spielplatz. |
| Der Sand ist nass. Theo buddelt im nass\_ Sand. | Theo buddelt im nassen Sand. |
| Der Baum ist hoch. Dies\_ hoh\_ Baum ist gefährlich. | Dieser hohe Baum ist gefährlich. |

## Stufe 7 (Nebensätze)

| Situation / Frage | Antwort |
|---|---:|
| Warum bekommt Marie das Laufrad? (Julian, ein Fahrrad bekommen) | Sie bekommt das Laufrad, weil Julian ein Fahrrad bekommen hat. |
| Was versuchen Mia und Luca? (den Drachen, vom Dach herunterholen) | Sie versuchen, den Drachen vom Dach herunterzuholen. |
| Wann gehen wir auf den Spielplatz? (der Regen, aufhören) | Wir gehen, wenn der Regen aufhört. |
| Wozu hält Papa das Fahrrad fest? (Julian, nicht umfallen) | Er hält es fest, damit Julian nicht umfällt. |
| Was denkt Marie? (Julian, das Laufrad zurückwollen) | Sie denkt, dass Julian das Laufrad zurückwill. |
| Es regnet. Bleiben die Kinder drinnen? (draußen spielen) | Obwohl es regnet, spielen sie draußen. |
