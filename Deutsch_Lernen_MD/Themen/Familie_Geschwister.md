# Familie & Geschwister

## Stufe 1 — Situation → Wer?

| Situation / Frage | Antwort |
|---|---:|
| Paul und Lisa haben dieselbe Mama. Lisa ist ein Mädchen. Wer ist Lisa für Paul? | Das ist seine Schwester. |
| Leo und Sofie haben dieselben Eltern. Leo ist ein Junge. Wer ist Leo für Sofie? | Das ist ihr Bruder. |
| Die Mama und der Papa von Tim zusammen. | Das sind seine Eltern. |
| Der Papa von Tims Papa bringt ihn in den Kindergarten. | Das ist sein Opa. |
| Die Mama von deiner Mama. | Das ist meine Oma. |
| Die Schwester von deinem Papa. | Das ist meine Tante. |
| Der Bruder von deiner Mama. | Das ist mein Onkel. |
| Der Sohn von deiner Tante. | Das ist mein CouSIN. |
| Die Tochter von deinem Onkel. | Das ist meine CouSIne. |
| In Mamas Bauch wächst Mia. | Das ist ein Baby. |
| Jonas spielt jeden Tag mit Lara. Lara ist ein Mädchen. | Das ist seine Freundin. |
| Paul hat eine Schwester, Lisa hat einen Bruder. Was sind sie zusammen? | Sie sind Geschwister. |
| Du hast zwei Jungen und ein Mädchen als Geschwister. | Ich habe zwei Brüder und eine Schwester. |
| Mama, Papa und alle Kinder zusammen. | Das ist unsere FaMIlie. |
| Lisa ist weg. Paul denkt die ganze Zeit an sie. | Er vermisst seine Schwester. |
| Stella liegt ganz nah bei Jonathan im Bett. | Sie kuschelt mit ihrem Bruder. |
| Mama nimmt Amelie auf den Arm und küsst sie lange. | Mama schmust mit Amelie. |
| Nele weiß: Bald kommt Mia. Sie lacht. | Sie freut sich auf ihre Schwester. |

## Stufe 2 — Fragen

| Situation / Frage | Antwort |
|---|---:|
| W\_\_ vermisst Paul? (Lisa) | (Wen?) Er vermisst seine Schwester. |
| W\_\_ vermisst du? (die Oma, wohnt weit weg) | (Wen?) Ich vermisse meine Oma. |
| \_\_\_ w\_\_ kuschelt Stella? (Jonathan) | (Mit wem?) Sie kuschelt mit ihrem Bruder. |
| \_\_\_ w\_\_ schmust Mama? (Amelie) | (Mit wem?) Sie schmust mit ihrer Tochter. |
| \_\_\_ w\_\_ freut sich Nele? (Mia) | (Auf wen?) Sie freut sich auf ihre Schwester. |
| W\_\_ besuchst du am Sonntag? (der Onkel) | (Wen?) Ich besuche meinen Onkel. |
| \_\_\_ w\_\_ telefonierst du? (die Tante) | (Mit wem?) Ich telefoniere mit meiner Tante. |
| W\_\_ gibst du das Geschenk? (der Cousin) | (Wem?) Ich gebe es meinem Cousin. |
| W\_\_ hilft Leo? (Mama) | (Wem?) Er hilft seiner Mama. |
| W\_\_ sitzt Luisa? (Papa, der Schoß) | (Wo?) Sie sitzt auf Papas Schoß. |
| W\_\_ wächst das Baby? (Mama, der Bauch) | (Wo?) In Mamas Bauch. |
| W\_\_ Hund ist Oskar? (Paul) | (Wessen?) Das ist Pauls Hund. |
| W\_\_ Zimmer ist das? (Stella) | (Wessen?) Das ist Stellas Zimmer. |

## Stufe 3 (Imperativ)

| Situation / Frage | Antwort |
|---|---:|
| Deine Tochter spielt allein, ihr Bruder steht traurig daneben. | Spiel doch mit deinem Bruder! |
| Dein Sohn nimmt seiner Schwester die Puppe weg. | Gib deiner Schwester die Puppe zurück! |
| Die Großen lachen, der Kleine ist hingefallen und weint. | Tröstet euren kleinen Bruder! |
| Die Kinder fahren eine Woche zu Oma. Du sagst zum Abschied: | Seid lieb zu Oma! |
| Deine Tochter kann nicht einschlafen. Ihre Schwester liegt schon im Bett. | Kuschel dich zu deiner Schwester! |
| Dein Sohn geht zu seinem Freund. Du kennst die Eltern gut. | Grüß seine Eltern von mir! |
| Du verabschiedest dich vom Nachbarn. Seine Frau ist nicht da. | Grüßen Sie Ihre Frau von mir! |

## Stufe 4 (Zeiten)

| Situation / Frage | Antwort |
|---|---:|
| Lisa war eine Nacht bei ihrer Freundin. Und Paul? | Er hat sie sehr vermisst. |
| Stella ist gestern zu Jonathan ins Bett gegangen. Und dann? | Sie hat mit ihm gekuschelt. |
| Gestern hatte Mama Amelie lange auf dem Arm. | Sie hat lange mit ihr geschmust. |
| Der Doktor hat gesagt: Nele bekommt eine Schwester. Und Nele? | Sie hat sich sehr gefreut. |
| Letzten Sommer: Oma und Opa. Was habt ihr gemacht? | Letzten Sommer haben wir Oma und Opa besucht. |
| Wie steht es im Buch? (Paul, seinen Hund, umarmen) | Paul umarmte seinen Hund. |
| – Sofie war noch nicht da. Wie war es früher für Leo?<br>– Und ein Kaninchen? | – Früher war Leo allein.<br>– Früher hatte er auch kein Kaninchen. |
| Bald kommt Mia. Was wird Nele dann? | Sie wird eine große Schwester. |
| Stell dir vor: Du hast keine Geschwister. | Dann wäre ich oft allein. |

## Stufe 5 (Ausdrücke)

| Situation / Frage | Antwort |
|---|---:|
| Im Kurs fragt man dich nach deiner Familie. | Ich bin verheiratet und habe drei Kinder. |
| Du willst wissen, ob dein Kollege Brüder oder Schwestern hat. | Hast du Geschwister? |
| Dein Freund kommt nach einem Monat zurück. | Ich hab dich vermisst! |
| Oma ruft an: Morgen kommt sie zu Besuch. | Ich freue mich auf dich! |
| Du verabschiedest dich von einem Freund. | Grüß deine Familie! |
| Ein Kollege kommt aus dem Urlaub zurück. | Wie geht's deiner Familie? |
| Der Kollege fragt zurück. Bei euch ist alles gut. | Danke, allen geht's gut. |
| Ein Kollege hat ein Baby bekommen. | Herzlichen Glückwunsch zum Baby! |
| Weihnachten: Oma, Opa, Tante, Onkel, alle sind da. | Die ganze Familie ist da. |
| Dein großer Sohn will auch im Kinderwagen fahren. | Dafür bist du schon viel zu groß! |
| Das Baby wird geschoben, dein Sohn muss laufen. Er sagt neidisch: | Das Baby hat es gut! |

## Stufe 7 (Nebensätze)

| Situation / Frage | Antwort |
|---|---:|
| Warum hat Leo keine Zeit mehr? (Sofie, jetzt da sein) | Er hat keine Zeit, weil jetzt Sofie da ist. |
| Wozu kuschelt sich Stella zu Jonathan? (nicht allein sein) | Sie kuschelt sich zu ihm, damit sie nicht allein ist. |
| Was hat der Doktor gesagt? (Nele, eine Schwester bekommen) | Er hat gesagt, dass Nele eine Schwester bekommt. |
| Wann darf Theo aus dem Kinderwagen? (so groß wie Jonas sein) | Er darf raus, wenn er so groß wie Jonas ist. |
| Was möchtest du vom Kollegen wissen? (Geschwister haben?) | Ich möchte wissen, ob du Geschwister hast. |
| Lisa ist nicht da. Und Paul? (trotzdem, sich freuen können) | Lisa ist nicht da. Trotzdem kann Paul sich freuen. |
