# Gelingen & Scheitern

> **Wer ist das Subjekt?**
> Die Sache (die Person im Dativ): *Es klappt. Das funktioniert. Mir gelingt es. Mir misslingt es. Das schlägt fehl. Das geht schief.*
> Die Person: *Ich schaffe das. Ich kriege das hin. Ich komme damit zurecht. Ich bewältige das. Ich scheitere daran.*
> **Perfekt mit sein**: gelungen, misslungen, gescheitert, fehlgeschlagen, schiefgegangen, zurechtgekommen. **Mit haben**: geklappt, funktioniert, geschafft, hingekriegt, bewältigt.
> **Umgangssprache**: klappen, hinkriegen, schiefgehen · **formell**: bewältigen, misslingen, fehlschlagen.

## Stufe 1 — Situation → Verb

| Situation / Frage | Antwort |
|---|---:|
| Dienstag, 10 Uhr? Ja, passt. | Ja, Dienstag klappt. |
| Drucker war kaputt, jetzt druckt er. | Er funktioNIERT wieder. |
| Erster Kuchen, sieht super aus. | Der Kuchen ist mir gelungen. |
| Prüfung bestanden, endlich! | Ich habe es geschafft! |
| Fahrrad kaputt, Papa repariert selbst. | Papa kriegt das hin. |
| Neues Programm, keine Probleme. | Ich komme gut damit zuRECHT. |
| Krise in der Firma, am Ende alles gut. | Die Firma hat die Krise bewältigt. |
| Projekt, kein Geld, Ende. | Das Projekt scheitert am Geld. |
| Kuchen schwarz, total verbrannt. | Der Kuchen ist mir missLUNgen. |
| Update installiert, Fehlermeldung. | Das Update ist fehlgeschlagen. |
| Regen, Bus weg, Kaffee auf der Hose. | Heute geht alles schief. |

## Stufe 3 — Fragen

| Situation / Frage | Antwort |
|---|---:|
| \_\_\_ w\_\_\_ hat es endlich geklappt? (Job) | (Womit?) Mit dem Job. |
| W\_\_ funktioniert nicht? (Drucker) | (Was?) Der Drucker funktioniert nicht. |
| W\_\_ gelingt der Kuchen immer? (Oma) | (Wem?) Meiner Oma gelingt er immer. |
| W\_\_ ist der Kuchen misslungen? (Papa) | (Wem?) Papa ist er misslungen. |
| W\_\_ schaffst du bis Freitag? (Bericht) | (Was?) Ich schaffe den Bericht bis Freitag. |
| \_\_\_ w\_\_ schafft ihr das? (Montag) | (Bis wann?) Bis Montag. |
| \_\_\_ w\_\_ hast du das geschafft? (Team) | (Mit wem?) Mit meinem Team. |
| W\_\_\_ kommst du nicht zurecht? (neues Programm) | (Womit?) Mit dem neuen Programm. |
| \_\_\_ w\_\_ kommt Leo gut zurecht? (Schwester) | (Mit wem?) Mit seiner Schwester. |
| W\_\_ hat das Team bewältigt? (Krise) | (Was?) Es hat die Krise bewältigt. |
| W\_\_\_ ist das Projekt gescheitert? (Geld) | (Woran?) Am Geld. |
| W\_\_\_ scheiterst du immer? (Grammatik) | (Woran?) An der Grammatik. |
| W\_\_ ist schiefgegangen? (Präsentation) | (Was?) Die Präsentation ist schiefgegangen. |

## Stufe 4 — Imperativ

| Situation / Frage | Antwort |
|---|---:|
| Der Bug muss bis morgen weg. Zum Kollegen: | Krieg das bitte bis morgen hin! |

## Stufe 5 — Zeiten

| Situation / Frage | Antwort |
|---|---:|
| Du hast den Job bekommen. Ein Freund fragt: „Und?“ | Es hat geklappt! |
| Heute ist das Programm kaputt. Und gestern? | Gestern hat es noch funktioniert! |
| Dein Sohn backt zum ersten Mal Pfannkuchen. Sie sind super. | Die Pfannkuchen sind ihm gelungen. |
| Wie steht es im Buch? (Julian, endlich, losfahren) | Endlich gelang es Julian loszufahren. |
| Gestern Deadline, alles war fertig. | Wir haben es rechtzeitig geschafft. |
| Chef: „Ist das realistisch?“ Du bist sicher. (werden) | Wir werden das schaffen. |
| Der Kunde wartet, Freitag ist Deadline. (müssen) | Wir müssen das bis Freitag schaffen. |
| Ohne Team, ganz allein? (würde) | Allein würde ich das nicht schaffen. |
| Die Waschmaschine war kaputt. Du hast sie selbst repariert. | Ich habe sie selbst hingekriegt. |
| Dein erster Monat in Deutschland. Und? (gut) | Ich bin gut zurechtgekommen. |
| Vorstellungsgespräch: „Wie war Ihr letztes Projekt?“ Viel Stress, am Ende alles gut. | Wir haben alle Probleme bewältigt. |
| Letztes Jahr: ein Startup, aber kein Geld. | Das Startup ist am Geld gescheitert. |
| Wie steht es im Buch? (der erste Versuch, nicht gut) | Der erste Versuch misslang. |
| Heute Nacht: Backup, am Morgen eine Fehlermeldung. | Das Backup ist fehlgeschlagen. |
| Gestern Präsentation: Beamer kaputt, Folien weg. | Gestern ist alles schiefgegangen. |
| Morgen ist die Prüfung, du hast alles gelernt. Dein Freund sagt: (können, nichts) | Da kann nichts schiefgehen. |

## Stufe 6 — Ausdrücke

| Situation / Frage | Antwort |
|---|---:|
| Ein Kollege kommt vom Amt zurück. Du fragst: | Hat alles geklappt? |
| Tester: „Der Button geht nicht.“ Auf deinem Laptop ist alles okay. | Bei mir funktioniert es aber! |
| Omas Geburtstag: Sie weiß nichts, alle rufen „Überraschung!“, sie lacht. | Die Überraschung ist gelungen! |
| Deine Tochter hat morgen ein Diktat und Angst. | Du schaffst das! |
| Langer Tag, endlich Feierabend. | Geschafft! |
| Der Chef gibt dir noch eine Aufgabe. Keine Zeit. | Das schaffe ich zeitlich nicht. |
| Umzug am Wochenende. Keiner hat Lust, aber es muss sein. | Augen zu und durch, wir schaffen das! |
| Vorstellungsgespräch: „Erzählen Sie von einem Erfolg.“ (Ladezeit, halbieren) | Ich habe es geschafft, die Ladezeit zu halbieren. |
| Dein Sohn hat allein einen hohen Turm gebaut. | Das hast du toll hingekriegt! |
| Neuer Kollege, erster Tag. Du fragst freundlich: | Kommst du zurecht? |
| Vorstellungsgespräch: „Wie gehen Sie mit Stress um?“ | Stress kann ich gut bewältigen. |
| Deine Tochter will Geige lernen, aber das kostet. Du sagst: | Am Geld soll es nicht scheitern. |
| Du erzählst einen Witz, keiner lacht. | Der Witz ist misslungen. |
| Falsches Passwort. Auf dem Bildschirm steht: | Anmeldung fehlgeschlagen. |
| Freitag, 17 Uhr, Release live. Der Kollege lacht: | Was soll schon schiefgehen? |

## Stufe 7b — Adverb + Verb

| Situation / Frage | Antwort |
|---|---:|
| Umzug nach Plan: keine Probleme, keine Pause. | Alles hat reibungslos geklappt. |
| Getestet: keine Fehler, nichts hängt. | Das Programm funktioniert einwandfrei. |
| Bis Freitag? Viel Zeit, kleine Aufgabe. | Das schaffen wir locker. |
| Dein Sohn ist acht und löst Aufgaben für die vierte Klasse. | Er schafft das spielend. |
| Viel zu viel Arbeit für eine Woche. | Das schaffen wir kaum. |
| Wenig Zeit, kein Plan, aber der Kunde wartet. | Das kriegen wir irgendwie hin. |
| Oma ist 85 und wohnt ohne Hilfe. | Sie kommt noch allein zurecht. |
| Großer Plan, peinliches Ergebnis. | Der Plan ist kläglich gescheitert. |
| Kuchen verbrannt, Gäste zu früh, der Hund frisst die Torte. | Das ist gründlich schiefgegangen. |
