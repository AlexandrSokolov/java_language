# es oder das?

> **es / ihn / sie** steht direkt nach dem Verb, vor **mir**: *Zeig es mir! Gib ihn mir!*
> **das** und Nomen stehen nach **mir**: *Zeig mir das! Zeig mir das Bild!*
> **es** nur für das-Wörter oder die ganze Situation: der Stift → *ihn*, die Lösung → *sie*, die Fotos → *sie*.
> **den / die** (= „diesen / diese“) stehen wie **das** nach **mir**: *Gib mir den! Erklär mir die!*

## Stufe 1 — es / ihn / sie oder das?

| Situation / Frage | Antwort |
|---|---:|
| Deine Tochter hat ein Bild gemalt. (zeigen, das Bild) | Zeig es mir!<br>Zeig mir das!<br>Zeig mir das Bild! |
| Dein Sohn hat einen neuen Stift. Du brauchst ihn kurz. (geben, der Stift) | Gib ihn mir!<br>Gib mir das!<br>Gib mir den Stift! |
| Der Kollege hat die Lösung gefunden. Du verstehst nichts. (erklären, die Lösung) | Erklär sie mir!<br>Erklär mir das!<br>Erklär mir die Lösung! |
| Du verstehst das Problem im Code nicht. Du fragst den Kollegen. (können, erklären) | Kannst du es mir erklären?<br>Kannst du mir das erklären?<br>Kannst du mir das Problem erklären? |
| Du verstehst das Problem nicht. Du fragst deinen Chef höflich. (Sie, können, erklären) | Können Sie es mir erklären?<br>Können Sie mir das erklären?<br>Könnten Sie mir das bitte erklären? |
| Deine Tochter hat die Hausaufgabe gemacht. Du willst sie sehen. (zeigen, die Hausaufgabe) | Zeig sie mir!<br>Zeig mir das!<br>Zeig mir die Hausaufgabe! |
| Ein Freund fragt: „Hast du den neuen Film gesehen?“ Ja. (sehen, der Film) | Ja, ich hab ihn gesehen.<br>Ja, ich hab das gesehen.<br>Ja, ich hab den Film gesehen. |
| Deine Freundin war im Urlaub und hat viele Fotos. (zeigen, die Fotos) | Zeig sie mir!<br>Zeig mir die Fotos! |
| Dein Sohn hat ein Geheimnis. (sagen, das Geheimnis) | Sag es mir!<br>Sag mir das!<br>Sag mir dein Geheimnis! |
| Das Nachbarskind hat den Ball deiner Tochter. Was ruft sie? (zurückgeben, der Ball) | Gib ihn mir zurück!<br>Gib mir den Ball zurück! |
| Dein Kind kommt aufgeregt nach Hause. Etwas ist passiert. (erzählen) | Erzähl es mir!<br>Erzähl mir das!<br>Erzähl mir alles! |
| Beim Amt verstehst du das Formular nicht. (Sie, erklären, das Formular) | Erklären Sie es mir bitte!<br>Erklären Sie mir das bitte!<br>Erklären Sie mir bitte das Formular! |
| Dein Sohn geht in die Schule. Sein Pausenbrot liegt noch auf dem Tisch. (vergessen, das Pausenbrot) | Vergiss es nicht!<br>Vergiss das nicht!<br>Vergiss dein Pausenbrot nicht! |
| – Dein Sohn geht zum Fußball. Seine Trinkflasche steht noch in der Küche. (vergessen, die Trinkflasche)<br>– Jetzt ist er weg, die Flasche steht immer noch da. | – Vergiss sie nicht!<br>Vergiss das nicht!<br>– Er hat sie vergessen. |
| Die Kinder gehen raus, es ist kalt. Die Mützen liegen im Flur. (vergessen, die Mützen) | Vergesst sie nicht!<br>Vergesst eure Mützen nicht! |
| Dein Freund fragt: „Leihst du mir dein neues Auto?“ Keine Chance! (vergessen) | Vergiss es! |

## Stufe 2 — den, die oder das?

| Situation / Frage | Antwort |
|---|---:|
| Dein Sohn hat einen neuen Stift. Du brauchst ihn kurz. (geben, der Stift) | Gib mir den! |
| Der Kollege hat die Lösung gefunden. Du verstehst nichts. (erklären, die Lösung) | Erklär mir die! |
| Deine Freundin war im Urlaub und hat viele Fotos. (zeigen, die Fotos) | Zeig mir die! |
| Ein Freund fragt: „Hast du den neuen Film gesehen?“ Ja. (sehen, der Film) | Ja, den hab ich gesehen. |
| Dein Sohn geht zum Fußball. Seine Trinkflasche steht noch in der Küche. (vergessen, die Trinkflasche) | Vergiss die nicht! |

## Stufe 3 — schnell gesprochen ('s)

| Situation / Frage | Antwort |
|---|---:|
| Du suchst lange die Lösung. Plötzlich weißt du sie! (haben) | Ich hab's! |
| Ein Kollege fragt: „Hast du die Mail gesehen?“ Ja. (sehen) | Ja, ich hab's gesehen. |
| Du solltest Brot kaufen, aber du hast nicht daran gedacht. (vergessen) | Ich hab's vergessen. |
| Der Lehrer erklärt die Regel und fragt dann. Alles klar. (verstehen) | Ja, ich hab's verstanden. |
| Du verstehst das Problem im Code nicht. Du fragst den Kollegen. (können, erklären) | Kannst du's mir erklären? |
| Du hast etwas Neues gekauft. Dein Freund ist neugierig. (wollen, sehen) | Willst du's sehen? |
| Deine Tochter versteckt etwas hinter dem Rücken. (zeigen) | Zeig's mir! |
| Du willst die Wahrheit hören. (sagen, ehrlich) | Sag's mir ehrlich! |
| Dein Sohn spielt schon lange mit deinem Handy. (geben, zurück) | Gib's mir zurück! |
| Im Café willst du wissen, ob es Internet gibt. (geben, WLAN) | Gibt's hier WLAN? |
| Ein Kollege kommt an deinen Tisch. Du fragst kurz: (geben, was) | Was gibt's? |
| Dein Freund geht nach Hause. Du verabschiedest dich. (machen, gut) | Mach's gut! |
| Die Prüfung ist schwer, aber du glaubst an dich. (schaffen) | Ich schaff's! |
| Das Projekt ist endlich fertig! (wir, schaffen) | Wir haben's geschafft! |

## Stufe 4 — Satzbau (Modalverb, lassen, trennbare Verben)

> Das Verb bildet einen Rahmen: *kannst … zeigen, bringe … mit, habe … zurückgebracht, muss … reparieren lassen*.
> **es / ihn / sie** und **das** stehen in der Mitte, wie immer: Pronomen vor **mir / dir / ihm**, **das** und Nomen danach.
> Bei **lassen** steht die Person im Akkusativ: *Lass **mich** das lesen!* (nicht *mir*)

| Situation / Frage | Antwort |
|---|---:|
| Dein Kollege hat einen Fehler im Code gefunden. Du willst ihn sehen. (können, zeigen, der Fehler) | Kannst du ihn mir zeigen?<br>Kannst du mir das zeigen?<br>Kannst du mir den Fehler zeigen? |
| Dein Sohn hat das Tablet seiner Schwester genommen. (müssen, zurückgeben) | Du musst es ihr zurückgeben!<br>Du musst ihr das zurückgeben!<br>Du musst ihr das Tablet zurückgeben! |
| Die Kinder liegen im Bett und wollen das neue Buch hören. (können, vorlesen, uns) | Kannst du es uns vorlesen?<br>Kannst du uns das vorlesen?<br>Kannst du uns das Buch vorlesen? |
| Der Kollege braucht dein Ladekabel, aber es ist zu Hause. (mitbringen, morgen) | Ich bringe es dir morgen mit.<br>Ich bringe dir das morgen mit.<br>Ich bringe dir das Kabel morgen mit. |
| Der Chef will die Präsentation sehen. (zuschicken, Sie, morgen) | Ich schicke sie Ihnen morgen zu.<br>Ich schicke Ihnen das morgen zu.<br>Ich schicke Ihnen die Präsentation morgen zu. |
| Deine Frau fragt: „Und die Bohrmaschine vom Nachbarn?“ (zurückbringen, schon) | Ich habe sie ihm schon zurückgebracht.<br>Ich habe ihm das schon zurückgebracht.<br>Ich habe ihm die Bohrmaschine schon zurückgebracht. |
| Deine Frau hat eine Nachricht vom Lehrer bekommen. Du willst sie lesen. (lassen, lesen, die Nachricht) | Lass sie mich lesen!<br>Lass mich das lesen!<br>Lass mich die Nachricht lesen! |
| Deine Tochter hat ein neues Lied gelernt. (lassen, hören, das Lied) | Lass es mich hören!<br>Lass mich das hören!<br>Lass mich das Lied hören! |
| Dein Sohn baut ein Lego-Auto, aber es klappt nicht. Du willst helfen. (lassen, versuchen) | Lass es mich versuchen!<br>Lass mich das versuchen! |
| Der Chef ist sauer, aber es war nicht deine Schuld. (Sie, lassen, erklären) | Lassen Sie es mich erklären!<br>Lassen Sie mich das erklären! |
| Dein Handy ist kaputt. Selbst kannst du nichts machen. (müssen, reparieren lassen) | Ich muss es reparieren lassen.<br>Ich muss das reparieren lassen.<br>Ich muss mein Handy reparieren lassen. |
| Gestern war das Handy kaputt, heute geht es wieder. Was hast du gemacht? (reparieren lassen) | Ich habe es reparieren lassen.<br>Ich habe das reparieren lassen. |
| Du willst den Kollegen höflich um Hilfe bitten. (fragen wollen, ob, erklären können) | Ich wollte fragen, ob du es mir erklären kannst.<br>Ich wollte fragen, ob du mir das erklären kannst. |
