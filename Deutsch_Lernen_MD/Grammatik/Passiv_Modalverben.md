# Passiv + Modalverben

> Passiv: **werden** + Partizip II: *Das Auto **wird** repariert.*
> Mit Modalverb: Partizip II + **werden** am Ende: *Das Auto **muss** repariert **werden**.*
> Vergangenheit: *Das Auto **wurde** repariert. / Das Auto **ist** repariert **worden**.* (nicht *geworden*)
> Im Nebensatz steht das Modalverb ganz am Ende: *…, weil es repariert werden **muss**.*

## Stufe 1 — Passiv Präsens

| Situation / Frage | Antwort |
|---|---:|
| Dein Auto ist in der Werkstatt. Ein Kollege fragt: „Wo ist dein Auto?“ (reparieren) | Es wird gerade repariert. |
| In der Bäckerei ist das Brot jeden Morgen frisch. (backen) | Das Brot wird jeden Morgen frisch gebacken. |
| Ein Kollege fragt: „Wann bekommen wir das neue Programm?“ (installieren, heute Abend) | Es wird heute Abend installiert. |
| Der neue Nachbar fragt: „Wann kommt die Müllabfuhr?“ (abholen, dienstags) | Der Müll wird dienstags abgeholt. |
| Am Spielplatz stehen Bagger. Dein Sohn fragt: „Was ist hier los?“ (bauen, neu) | Hier wird ein neuer Spielplatz gebaut. |

## Stufe 2 — Passiv Vergangenheit

> In der Sprache meistens *wurde*. *ist … worden* muss man verstehen.

| Situation / Frage | Antwort |
|---|---:|
| Gestern war die Heizung kaputt, heute ist es warm. (reparieren) | Die Heizung wurde repariert.<br>Die Heizung ist repariert worden. |
| Du kommst zum Auto zurück. Das Fenster ist kaputt, dein Laptop ist weg. (stehlen) | Mein Laptop wurde gestohlen.<br>Mein Laptop ist gestohlen worden. |
| Das Meeting war gestern geplant, aber es hat nicht stattgefunden. (verschieben) | Das Meeting wurde verschoben. |
| Deine Frau fragt: „Und? Wie war das Vorstellungsgespräch?“ Du hast den Job! (nehmen) | Ich wurde genommen!<br>Ich bin genommen worden! |
| Wie steht es im Buch? (das Haus, 1900, bauen) | Das Haus wurde 1900 gebaut. |

## Stufe 3 — Modalverb + Passiv

| Situation / Frage | Antwort |
|---|---:|
| Die Software hat noch Fehler. Vor dem Release … (testen) | Sie muss noch getestet werden. |
| Beim Amt fragst du: „Wo unterschreibe ich?“ Die Beamtin zeigt nach unten. (unterschreiben) | Das Formular muss hier unten unterschrieben werden. |
| Die Waschmaschine ist kaputt, aber der Mechaniker ist optimistisch. (reparieren) | Die kann repariert werden. |
| Der Chef fragt: „Wann soll das Paket beim Kunden sein?“ Der Kunde will es morgen. (liefern) | Es soll morgen geliefert werden. |
| Ihr zieht aus. Die Wand im Kinderzimmer ist bunt. Der Vermieter sagt: (streichen, weiß) | Die Wand muss weiß gestrichen werden. |

## Stufe 4 — Verneinung

| Situation / Frage | Antwort |
|---|---:|
| Morgen ist die Abgabe. Das ist super wichtig. (vergessen) | Das darf nicht vergessen werden. |
| Im Krankenhaus hängt ein Schild mit einer Zigarette. (rauchen) | Hier darf nicht geraucht werden. |
| Das T-Shirt ist neu und sauber. Deine Frau will es waschen. (waschen) | Das muss nicht gewaschen werden.<br>Das braucht nicht gewaschen zu werden. |
| Die Daten der Kunden sind geheim. (weitergeben) | Die Daten dürfen nicht weitergegeben werden. |
| Im Text ist ein kleiner Fehler, aber den Text liest nur dein Team. (korrigieren) | Das muss nicht korrigiert werden. |

## Stufe 5 — Zeiten mit Modalverb

> Im Präteritum: *musste repariert werden, konnte gelöst werden*.

| Situation / Frage | Antwort |
|---|---:|
| Letzte Woche ist ein Baum auf dein Auto gefallen. (abschleppen) | Es musste abgeschleppt werden. |
| Gestern gab es ein Problem auf dem Server, aber nach einer Stunde lief alles wieder. (lösen, schnell) | Das Problem konnte schnell gelöst werden. |
| Dein Sohn war im Krankenhaus, der Arm war gebrochen. (operieren) | Er musste operiert werden. |
| Die Party war draußen geplant, aber es hat geregnet. (verschieben) | Die Party musste verschoben werden. |
| Das alte Handy ist ins Wasser gefallen. Und? (retten, nicht mehr) | Es konnte nicht mehr gerettet werden. |

## Stufe 6 — Konjunktiv: Rat & Plan

| Situation / Frage | Antwort |
|---|---:|
| Im Meeting: Der Bericht ist noch nicht fertig, Deadline ist Freitag. (erledigen) | Das sollte bis Freitag erledigt werden. |
| Die neue Funktion ist fertig, aber keiner hat sie geprüft. (eigentlich, testen) | Das müsste eigentlich noch getestet werden. |
| Ein Kunde fragt: „Geht das bis morgen?“ Du bist vorsichtig optimistisch. (liefern) | Das könnte bis morgen geliefert werden. |
| Die Fenster im Büro sind alt, es ist immer kalt. (austauschen) | Die Fenster sollten ausgetauscht werden. |
| Der Chef fragt: „Was machen wir mit dem alten Code?“ (neu schreiben) | Der Code sollte neu geschrieben werden. |

## Stufe 7 — Nebensätze

| Situation / Frage | Antwort |
|---|---:|
| Der Chef fragt: „Warum ist das Release verschoben?“ (weil, noch testen) | Weil es noch getestet werden muss. |
| Deine Frau fragt: „Was hat der Vermieter geschrieben?“ (dass, die Heizung, nächste Woche, reparieren) | Er hat geschrieben, dass die Heizung nächste Woche repariert wird. |
| Ein Kollege fragt: „Kommt das Update heute?“ Du weißt es nicht. (ob, heute installieren) | Ich weiß nicht, ob es heute installiert wird. |
| Ein Kollege fragt: „Warum bist du mit dem Bus gekommen?“ (weil, das Auto, abschleppen) | Weil das Auto abgeschleppt werden musste. |
| Dein Auto war letzte Woche in der Werkstatt. Jetzt macht es wieder komische Geräusche. (obwohl, reparieren) | Obwohl es repariert wurde, macht es wieder Geräusche. |

## Stufe 8 — Passiv, man oder lassen?

> Eine Situation, mehrere Antworten: Passiv, mit **man** / Person, mit **sich lassen**.

| Situation / Frage | Antwort |
|---|---:|
| Das alte Fahrrad ist kaputt, aber der Mechaniker ist optimistisch. | Es kann repariert werden.<br>Man kann es reparieren.<br>Es lässt sich reparieren. |
| Im Krankenhaus hängt ein Schild mit einer Zigarette. | Hier darf nicht geraucht werden.<br>Hier darf man nicht rauchen. |
| Die Software hat noch Fehler. Vor dem Release … | Sie muss noch getestet werden.<br>Wir müssen sie noch testen. |
| Das Fenster klemmt. Du drückst und drückst, nichts passiert. | Das Fenster kann nicht geöffnet werden.<br>Man kann das Fenster nicht öffnen.<br>Das Fenster lässt sich nicht öffnen. |
| Der Chef fragt: „Schaffen wir das bis Freitag?“ Du bist optimistisch. | Das kann bis Freitag gemacht werden.<br>Das können wir bis Freitag machen.<br>Das lässt sich bis Freitag machen. |
