# Pronominaladverbien (da-Wörter)

> **Sache** + Präposition → **da(r)- + Präposition**: *damit, daran, darüber*. **r**, wenn die Präposition mit Vokal beginnt: *dar-an, dar-über*.
> **Person** + Präposition → Präposition + Pronomen: *mit ihm, an sie, über ihn*.
> **Fragen**: Sache → **wo(r)-**: *womit? woran? worüber?* · Person → *mit wem? an wen? über wen?*
> **Umgangssprache**: *dran, drüber*: *Ich bin dran. Wir reden später drüber.*
> **Verben**: **mit** — spielen, anfangen, aufhören, zufrieden sein · **an** — denken, sich erinnern, arbeiten · **über** — sprechen, sich freuen, sich ärgern, lachen

## Stufe 1 — Sache → da-Wort

| Situation / Frage | Antwort |
|---|---:|
| Neues Lego. Die Kinder, den ganzen Nachmittag. | Sie spielen damit. |
| Deutschkurs ab Montag. Du startest. | Ich fange am Montag damit an. |
| Rauchen. Seit Januar nicht mehr. | Ich habe damit aufgehört. |
| Neues Auto. Alles super. | Ich bin sehr zufrieden damit. |
| Morgen Omas Geburtstag. Nicht vergessen! | Ich denke daran. |
| Urlaub in Italien, vor zehn Jahren. Noch im Kopf. | Ich erinnere mich gut daran. |
| Bug seit Montag, jeden Tag drei Stunden. | Ich arbeite daran. |
| Neue Wohnung. Beim Abendessen nur ein Thema. | Wir sprechen darüber. |
| Geschenk von Oma. Die Tochter strahlt. | Sie freut sich darüber. |
| Stau, schon wieder. Du bist sauer. | Ich ärgere mich darüber. |
| Papas Witz. Alle: „Haha!“ | Alle lachen darüber. |

## Stufe 2 — Sache oder Person?

| Situation / Frage | Antwort |
|---|---:|
| Neuer Kollege, sehr nett, gute Arbeit. | Ich bin sehr zufrieden mit ihm. |
| Oma, weit weg. Du vermisst sie. | Ich denke oft an sie. |
| Neues Handy: Kamera super, Akku super. | Ich bin zufrieden damit. |
| Der Hund. Die Kinder, den ganzen Tag im Garten. | Sie spielen mit ihm. |
| Erster Schultag, 30 Jahre her. Noch im Kopf. | Ich erinnere mich gut daran. |
| Der Lehrer aus der ersten Klasse. Er war toll. | Ich erinnere mich gut an ihn. |
| Das Meeting gestern. Die Kollegen, in der Pause, nur ein Thema. | Sie sprechen darüber. |
| Der neue Chef. Die Kollegen, in der Pause, nur ein Thema. | Sie sprechen über ihn. |
| Der kleine Bruder nimmt immer ihr Spielzeug. Sie ist sauer. | Sie ärgert sich über ihn. |
| Der Clown im Zirkus. Die Kinder: „Haha!“ | Sie lachen über ihn. |

## Stufe 3 — Fragen

| Situation / Frage | Antwort |
|---|---:|
| W\_\_\_ denkst du? (Urlaub) | (Woran?) An den Urlaub. |
| \_\_\_ w\_\_ denkst du? (Oma) | (An wen?) An meine Oma. |
| W\_\_\_ spielen die Kinder? (Ball) | (Womit?) Mit dem Ball. |
| \_\_\_ w\_\_ spielt dein Sohn? (Nachbarskind) | (Mit wem?) Mit dem Nachbarskind. |
| W\_\_\_ sprecht ihr? (Umzug) | (Worüber?) Über den Umzug. |
| \_\_\_ w\_\_ sprecht ihr? (neuer Chef) | (Über wen?) Über den neuen Chef. |
| W\_\_\_ arbeitest du gerade? (neue App) | (Woran?) An der neuen App. |
| W\_\_\_ ärgerst du dich? (Stau) | (Worüber?) Über den Stau. |
| W\_\_\_ hast du aufgehört? (Rauchen) | (Womit?) Mit dem Rauchen. |

## Stufe 4 — da-Wort am Satzanfang

| Situation / Frage | Antwort |
|---|---:|
| Arzttermin heute. Total vergessen! | Daran habe ich nicht gedacht! |
| Präsentation für Freitag. Gestern: Start. | Damit habe ich gestern angefangen. |
| Projekt gut gelaufen. Der Chef lobt dich. | Damit bin ich sehr zufrieden. |
| Kollege fragt nach deinem Streit zu Hause. Du willst nicht. | Darüber will ich nicht sprechen. |
| Deine Tochter bekommt ein Fahrrad zum Geburtstag. | Darüber hat sie sich riesig gefreut. |
| Bug seit drei Tagen. Morgen weiter. | Daran muss ich morgen weiterarbeiten. |

## Stufe 5 — Umgangssprache: dran, drüber

| Situation / Frage | Antwort |
|---|---:|
| Kollege: „Und der Bug?“ Schon in Arbeit. | Ich bin schon dran. |
| Brettspiel. Jetzt dein Sohn. | Du bist dran! |
| Kollegin: „Morgen Termin, nicht vergessen!“ | Ich denk dran! |
| Wichtiges Thema, aber jetzt keine Zeit. | Wir reden später drüber. |
| Witz vom Chef, keiner lacht. Später im Flur: | Jetzt lachen alle drüber. |

## Stufe 6 — Ausdrücke

| Situation / Frage | Antwort |
|---|---:|
| Schlechte Nachricht, total überraschend. | Damit habe ich nicht gerechnet. |
| Kollege gibt dir die Schuld, aber es war nicht deine Aufgabe. | Damit habe ich nichts zu tun. |
| Neue Regel im Büro. Du findest sie gut. | Damit bin ich einverstanden. |
| Essen vom Lieferservice: nicht super, aber okay. | Damit kann ich leben. |
| Der Fehler ist passiert, man kann nichts mehr machen. | Daran ist nichts zu ändern. |
| Kollege fragt nach deinem Gehalt. | Darüber spricht man nicht. |
| Witz über eine Krankheit. Du sagst ernst: | Darüber lacht man nicht. |
