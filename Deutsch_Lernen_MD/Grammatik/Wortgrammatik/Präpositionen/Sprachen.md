# Sprachen

> **ohne Präposition** — die Sprache können, sprechen, lernen: *Ich spreche Deutsch.*
> **auf** — in welcher Sprache etwas gesagt oder geschrieben ist: *Sag das auf Deutsch!*
> **in** — Schulfach, Note, Prüfung: *Ich habe eine Zwei in Deutsch.*

## Stufe 1 — ohne Präposition, auf oder in?

| Situation / Frage | Antwort |
|---|---:|
| Kollege spricht Englisch. Du willst üben. | Können wir auf Deutsch sprechen? |
| Zeugnis deiner Tochter: Deutsch – 2. | Sie hat eine Zwei in Deutsch. |
| Kurs. „Und Englisch?“ Ja. | Ja, ich kann Englisch. |
| Kino, Originalversion aus den USA. | Der Film ist auf Englisch. |
| Englischtest deines Sohnes: 1! | In Englisch ist er sehr gut. |
| Neuer Arzt aus Spanien. Du fragst höflich. | Sprechen Sie Deutsch? |
| Ein Wort fehlt dir. Du fragst den Kollegen. | Wie heißt das auf Deutsch? |
| Abitur, Fach Deutsch. Gar nicht leicht. | Die Prüfung in Deutsch war schwer. |
| Vorstellungsgespräch. Dein Deutsch: noch schwach. | Ich spreche noch nicht so gut Deutsch. |
| Sohn spricht Russisch. Oma versteht nichts. | Sag das auf Deutsch! |
| Elternabend. Englisch: schwach. | In Englisch hat er Probleme. |
| Kurs, Bücher, jeden Tag. | Ich lerne Deutsch. |
| Brief vom Finanzamt. Sprache? | Der Brief ist natürlich auf Deutsch. |
