# SQL Syntax

Writing queries.

- Order in which clauses run — `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `SELECT`, `ORDER BY`.
- Joins — inner, left, right, full, cross.
- Grouping — `GROUP BY`, aggregates, `HAVING` vs `WHERE`.
- Subqueries — correlated subqueries, `EXISTS` vs `IN`.
- Window functions — `ROW_NUMBER`, `RANK`, running totals, `PARTITION BY`.
- CTEs — `WITH`, recursive queries.
- Upsert — `INSERT ... ON CONFLICT` (PostgreSQL), `ON DUPLICATE KEY UPDATE` (MySQL).
