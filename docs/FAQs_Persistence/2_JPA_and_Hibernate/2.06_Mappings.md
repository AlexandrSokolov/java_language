# Mappings

How entity fields map to tables and columns — everything except links between entities.

- Embeddables — `@Embeddable`, `@Embedded`, `@AttributeOverride`.
- Inheritance — `SINGLE_TABLE`, `JOINED`, `TABLE_PER_CLASS`, `@MappedSuperclass`.
- Converters — `AttributeConverter`, `@Convert`.
- Enums — `@Enumerated`: `ORDINAL` vs `STRING`.
- Value collections — `@ElementCollection`.
