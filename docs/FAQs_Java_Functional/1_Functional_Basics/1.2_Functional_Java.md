### What are Java lambdas?
<details><summary>Show answer</summary>

A lambda expression is a nameless block of code with zero or more parameters that may return a value.

</details>

### What type does a lambda have?
<details><summary>Show answer</summary>

Lambdas are represented by a specialized subtype of interfaces, so-called functional interfaces.
A functional interface — an interface with one abstract method.

</details>

### How to guarantee an interface stays functional?
<details><summary>Show answer</summary>

Mark it `@FunctionalInterface`. The compiler then rejects it if it ever has more than one abstract method, 
so a later added method can't silently break it.

</details>

### Can a lambda use outside variables?
<details><summary>Show answer</summary>

Yes — it "captures" variables and constants from the scope where it was defined. 
The captured value stays available even when the lambda runs later in another method, after that scope is gone.

```java
void capture() {
  var theAnswer = 42;
  Runnable r = () -> System.out.println("the answer is " + theAnswer);
  run(r);  // prints 42, though capture() has returned
}
```

</details>

### What's required of a captured variable?
<details><summary>Show answer</summary>

It must be effectively final — the reference can't be reassigned after it's set. 
Either mark it `final`, or just never reassign it.

The rule is about the reference, not the data. A captured `List` reference can't be reassigned, 
but you can still add to the list.

```java
var list = new ArrayList<String>();
Runnable r = () -> list.add("ok");  // fine: mutating, not reassigning
// list = new ArrayList<>();        // would break capture: reassignment
```

</details>

### How to use a reassigned variable in a lambda?
<details><summary>Show answer</summary>

Assign it to a new variable and don't touch that one — the new reference is effectively final, 
so the lambda can capture it. Only the reference needs to be stable.

```java
var count = 1_000L;
count = 9_000L;         // reassigned, so not effectively final
var fixed = count;      // new reference, never changed
Predicate<Long> over9000 = n -> n > fixed;
```

A workaround, not a goal — better to avoid needing it.

</details>

### How do you call a lambda in Java?
<details><summary>Show answer</summary>

By calling the interface's single abstract method — a lambda is just an instance of a functional interface, so you
can't invoke it directly.

```java
Function<String, String> hello = name -> "hello, " + name + "!";
var result = hello.apply("Ben");  // call the SAM
```

</details>
