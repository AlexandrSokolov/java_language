# Class Loading

How the JVM finds, loads and links classes, and what breaks.

- Delegation — bootstrap, platform and application class loaders; a loader asks its parent first.
- Custom class loaders — why servers and frameworks use them (Tomcat, Spring Boot jars).
- `ClassNotFoundException` vs `NoClassDefFoundError`.
- Class loader leaks — why a redeployed app can keep its old classes in memory.
