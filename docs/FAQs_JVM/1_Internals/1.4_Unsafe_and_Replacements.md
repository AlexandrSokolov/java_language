# Unsafe and Its Replacements

- `sun.misc.Unsafe` — what libraries used it for: memory outside the heap, compare-and-swap.
- Its status — memory-access methods deprecated for removal (JDK 23), run-time warnings (JDK 24).
- `VarHandle` — the supported way to do atomic and ordered access.
- Foreign Function & Memory API — the supported way to use memory outside the heap.
