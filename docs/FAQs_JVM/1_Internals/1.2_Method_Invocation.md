# Method Invocation

How a method call becomes bytecode, and how the JVM picks the method to run.

- The `invoke*` bytecodes — `invokestatic`, `invokespecial`, `invokevirtual`, `invokeinterface`.
- Virtual dispatch — choosing the override at run time.
- `invokedynamic` — the call is linked at run time; used by lambdas and string concatenation.
- Lambdas — no class file per lambda at compile time; a class is generated at run time on the first call.
