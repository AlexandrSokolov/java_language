# Java Language State

- **Strengths** — lasting ones: backward compatibility, the JVM, the ecosystem and tooling.
- **New features in use** — records, sealed types, pattern matching, switch expressions, text blocks, virtual threads.
- **Missing or weak** — null safety, value types, generics with erasure, checked exceptions, verbosity, no named
  parameters; FP limits → [FAQs_Java_Functional/1.2](../FAQs_Java_Functional/1_Functional_Basics/1.2_Limitations_of_Java_as_a_FP_language.md).
- **Coming** — Valhalla, Leyden, structured concurrency; each one linked from the gap it fixes.
