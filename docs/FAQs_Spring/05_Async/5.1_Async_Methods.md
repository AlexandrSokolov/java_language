# Async Methods

- `@EnableAsync` and `@Async` — run through a [proxy](../02_AOP_and_Transactions/2.1_Proxies_and_AOP.md);
  self-invocation runs the method in the same thread.
- Return types — `void`, `CompletableFuture`.
- Lost exceptions from `void` methods — `AsyncUncaughtExceptionHandler`.
- What doesn't follow to the new thread — transaction, security context;
  [context propagation](../../FAQs_Concurrency/3_JDK_Concurrency_Libraries/3.7_Context_Propagation.md).
