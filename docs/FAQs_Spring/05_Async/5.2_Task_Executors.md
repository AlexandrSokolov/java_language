# Task Executors

Which threads run `@Async` methods.

- The default executor — with and without Spring Boot.
- Pool settings — core size, max size, queue capacity; [sizing a pool](../../FAQs_Concurrency/4_Structuring_Concurrent_Tasks/4.5_Applying_Thread_Pools.md).
- Separate executors per kind of task.
- Virtual threads for `@Async`.
- Shutting down executors cleanly.
