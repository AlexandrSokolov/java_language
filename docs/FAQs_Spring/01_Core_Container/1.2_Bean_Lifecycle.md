# Bean Lifecycle

- Steps — instantiation, dependency injection, initialization, use, destruction.
- `BeanPostProcessor` — runs around initialization; where proxies are created.
- `BeanFactoryPostProcessor` vs `BeanPostProcessor`.
- Init callbacks — `@PostConstruct`, `InitializingBean`, `initMethod`.
- Destroy callbacks — `@PreDestroy`, `DisposableBean`, `destroyMethod`.
